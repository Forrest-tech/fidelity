# 合规知识库提问指南（员工用）

一页说明。无需安装任何东西：AI 工具（目前是 Grok）已经装好 `au-compliance-kb` 技能和 Dropbox 连接器。

## 怎么问
- 像问同事一样问，中文或英文都可以，例如："公共楼梯的最大踏步高度是多少？"不需要知道条款号。
- 涉及时请说明**州**和**建筑类别**（如 NSW、Class 2）。没说的话，AI 应该反问，或者按类别分别回答。
- 一次问一个问题最快：简单查询约 10–20 秒；需要查多个文件的问题会更久。

## 怎么看答案
每个答案有四行：
```
Answer:   条文要求（从知识库原文照抄）
Source:   文件、条款、页码        ← 关键数值请打开原文这一页核对
Status:   verified（已验证）/ pending review（待审核）
Edition:  标准和年份；适用地区
```
- **"Not found in the knowledge base"（知识库中未找到）**：知识库里没有时，这就是正确答案，AI 不能猜。
  它会列出用过的搜索词；如果你认为应该有，可以换个说法再问。
- **"公式不可读……请查看原文页"**：少数公式无法从 PDF 读出，请打开给出的页码查看。
- **草案，未生效（Draft, not in force）**：草案只作参考，AI 必须按正式版回答。
- **待审核 / 来自扫描件 / 图纸**：关键数值请先核对原件。
- **NSW 与 NCC 2025**：NSW 从 2027-05-01 起采用 NCC 2025，在此之前 NSW 仍适用 NCC 2022。

## 答案看起来不对时
直接告诉 AI："这个不对，应该是……"。它会重新读原文，并保存一份**错误报告**，由维护人员核查。
确认的错误会被修正，并加入测试题库，避免再犯。请不要自己修改知识库文件。

## 答案保存在哪里
每个答案都会保存到对话记录文件夹（对话的第一个答案里会写明，一般是 `/Library_Installation_Chat_Logs`）。
答案末尾的 `📁 Saved: …` 表示已保存。

## 不适用于
法律意见、项目审批，或知识库以外的内容。以原始文件为准。
