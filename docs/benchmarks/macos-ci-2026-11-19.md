# OCR and throughput on Apple silicon — GitHub macOS runner (2026-11-19)

From CI job `backend-tests-macos` (macOS 26.7, arm64, Python 3.11). The Mac mini will be measured with the
same scripts after `deploy/mac/install.sh`; these numbers are the first evidence on Apple hardware.

- Full backend test suite: **passes on macOS**.
- Synthetic scans (3 pages × 6 degradations), three engines installed — Apple Vision (accurate),
  RapidOCR (English model), Tesseract 5:
  - Apple Vision 99.4–100 % accuracy, 100 % recall; RapidOCR 99.8–100 %; Tesseract 99.5–99.8 %.
  - `--select` ranked by mean accuracy and chose **RapidOCR + Tesseract** for this machine (Apple Vision
    third on this synthetic set). Pages auto-accepted where the chosen engines agree; worst accepted 99.52 %.
- OCR speed: RapidOCR **4.2 s/page** (VM: 53 s), Tesseract **0.8 s/page** (VM: 4.8 s), images ≤ 1400 px.

The selection is re-made on each machine from its own benchmark (`data/ocr_engines.json`); real scans
(not synthetic) should be added to the benchmark set on the Mac mini before relying on the choice.
